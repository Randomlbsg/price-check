# test11

BTC price checker demo

This repository includes a small, self-contained frontend (index.html) that shows the current BTC / USD price and 24h change using the CoinGecko public API.

How to run
- Clone the repository:
  git clone https://github.com/Randomlbsg/test11.git
- Open the file `index.html` in your browser (double-click or serve via a static file server).

Files
- index.html — frontend that fetches BTC price from CoinGecko and updates every 10 seconds.

Notes
- The demo uses the public CoinGecko API. If you intend to run this in production or heavy-traffic environments, consider adding caching or using an API key/back-end proxy.
